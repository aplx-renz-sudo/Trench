                                                                                                Welcome to Trench guide!
How to launch :-
-> Go to terminal
-> Have python installed.
-> Now locate to the file named "main" in the Trench folder, once it says "../Trench/main" - run python/python3 trch.py (<- main python program)


How to setup :-
Note that you need to still type /help, but, heres how to plug in your APIs!
-> Once in, type this - /switch
-> once when the interface shows up - type your provider (First letter caps)
-> Then, type the model name (i.e, gemini-3.5-flash)
-> Lastly, enter your API key (NOTE! PLEASE NOTE THAT BEFORE YOU ENTER YOUR API KEY, MAKE SURE ITS STORED LOCALLY RATHER THAN IN THE PROGRAM - if you think to help out ofc :3)
-> Your in! Enjoy Trench!

for further details on trench, go to the readme.md in the "main" file, and in the main file, trch.py is the main file to launch
