# Trench
Welcome, to the sub product of VileDocx - Trench.

## Built on :-
Trench T01 is a layer ontop of the old python version/CLI version named - Aplx V1.6

## Capabilities :-
Works like the Web version of VileDocx but as a terminal one - incase if people want absolute privacy.

## Why trench? :-
Because Trench is a Terminal interface between you - user and your API provider, if you want to just sit back and use your AI to code.
